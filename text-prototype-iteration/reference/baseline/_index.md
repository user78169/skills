# 基线清单

本目录存放项目页面的当前状态快照，是迭代项目的参照基准。

## 使用规则

1. 步骤2 基线确认时，检查本目录是否存在该页面的基线
2. 基线不存在时，调用 `text-prototype-from-scratch` skill 生成当前状态，存入本目录
3. 迭代完成后（步骤7），将新版状态存为新基线，版本号递增
4. 基线保留历史版本，不覆盖旧版本（便于追溯）

## 版本管理规则

- 小版本（v1.0 → v1.1）：模块内部调整、文案修改、交互优化
- 大版本（v1.x → v2.0）：新增/删除模块、页面结构重组
