# 通用页面模板索引

本目录存放成熟页面的布局骨架，供迭代项目生成基线时复用。

## 使用规则

1. 步骤2b 生成基线时，根据页面类型匹配模板
2. 读取 `templates/<页面类型>.md` 获取布局骨架
3. 生成时：参考文档的骨架作为基础，具体文案和数据需结合用户场景调整
