# 通用页面模板索引

本目录存放成熟页面的布局骨架，供 0-1 项目从零搭建时复用。

## 使用规则

1. 步骤2 拟定页面草案后，根据页面清单识别每个页面的类型
2. 步骤4 生成原型前，读取 `templates/<页面类型>.md` 获取布局骨架
3. 生成时：参考文档的骨架作为基础，具体文案和数据需结合用户场景调整
